07 Zelfstandig bedrijf
Admin Dashboard — Pop And Clay
Beschrijving

Een volledig admin dashboard voor het zelfstandig keramiekbedrijf Pop And Clay. Via een C# Web API backend en een HTML/CSS/JavaScript frontend kunnen bestellingen, producten en klantgegevens beheerd worden in één overzichtelijke interface.

Technologieën

C# Web API · HTML & CSS · JavaScript · SQL Database

Persoonlijke uitdaging

De communicatie tussen de C# backend en de JavaScript frontend opzetten via de Web API. Het correct ophalen, tonen en verwerken van data vanuit de database vroeg veel uitzoekwerk.

Bijgeleerd

Hoe een full-stack applicatie in elkaar zit: van database over API tot UI. Ik heb geleerd hoe je REST-endpoints aanspreekt vanuit JavaScript en hoe je data dynamisch in een pagina laadt.
